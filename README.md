## Project Overview
- **Theme:** Artisan Café & Bakery (Warm Brown & Gold Theme)
- **Description:** A multi-page responsive bakery website showcasing freshly baked pastries, a seasonal menu, a photo gallery, and an interactive customer inquiry form.

## Website Pages
- **Home (`index.html`):** Welcome page introducing Golden Bakers with a featured highlight and quick navigation.
- **Menu (`menu.html`):** Categorized bakery and café menu featuring artisan breads, pastries, and specialty coffees.
- **Gallery (`gallery.html`):** Responsive grid gallery displaying signature baked goods and daily baking schedule alerts.
- **Contact (`contact.html`):** Bakery location, opening hours, and an interactive inquiry and pre-order form.

## AI Tools Used
- **Google Gemini:** Used for generating HTML/CSS structure, responsive layouts, interactive JavaScript features, and troubleshooting deployment.
